# Glossary

| Term | Meaning |
|---|---|
| **ADE** | Analog Design Environment: Virtuoso's simulation front end |
| **ADE L / XL / GXL** | Legacy ADE flavors (single test / multi-test / optimization) |
| **ADE Explorer / Assembler** | Current ADE flavors replacing L and XL; setups stored in `maestro` views |
| **AHDL** | Analog Hardware Description Language. In Spectre, means Verilog-A support |
| **AMS** | Analog/Mixed-Signal. Also short for Spectre AMS Designer |
| **APS** | Accelerated Parallel Simulator: a fast Spectre engine |
| **`amsd` block** | Section in an AMS control file binding cells to SPICE netlists and configuring IEs |
| **CDF** | Component Description Format: instance parameter definitions and callbacks |
| **CIW** | Command Interpreter Window: Virtuoso's main window and SKILL console |
| **CM / CR** | Connect Module / Connect Rules (AMS discipline converters) |
| **Config view** | Hierarchy Editor view selecting which view of each cell is simulated |
| **Corner** | One combination of process/voltage/temperature (PVT) conditions |
| **`cds.lib`** | File defining library names and locations |
| **DM** | Design management (version control for libraries) |
| **E2L / L2E** | Electrical-to-logic / logic-to-electrical connect modules |
| **Family** | Ocean/ViVA object holding one waveform/value per sweep point |
| **IE** | Interface Element: AMS connect module instance configured via IE cards |
| **IMC** | Incisive/Integrated Metrics Center: Xcelium coverage tool |
| **ISR** | Incremental Software Release (e.g. IC6.1.8 ISR30) |
| **maestro** | Cellview type storing ADE Explorer/Assembler setups |
| **MC** | Monte Carlo |
| **OA** | OpenAccess: the database underneath Virtuoso libraries |
| **Ocean** | SKILL-based scripting interface for simulation and analysis |
| **OSS / UNL** | Open Simulation System / Unified Netlister (netlisting infrastructures) |
| **PDK** | Process Design Kit: foundry-supplied models, devices, rules. **Never in this repo** |
| **PSF / PSF-XL** | Parameter Storage Format: Spectre result formats |
| **PVT** | Process, Voltage, Temperature |
| **RNM** | Real-Number Modeling (SV `real`, nettypes, `wreal`) |
| **SHM** | Xcelium/SimVision waveform database |
| **`si`** | Batch netlister ("simulation interface") |
| **SKILL / SKILL++** | Virtuoso's Lisp-based extension language / its lexically-scoped variant |
| **Snapshot** | Elaborated Xcelium design ready to simulate |
| **Spectre X / FX** | Newer Spectre engines (SPICE-accurate presets / FastSPICE) |
| **UVM** | Universal Verification Methodology (SystemVerilog) |
| **ViVA** | Virtuoso Visualization & Analysis: waveform viewer and calculator |
| **`xrun`** | Single-step Xcelium launcher (successor of `irun`) |
